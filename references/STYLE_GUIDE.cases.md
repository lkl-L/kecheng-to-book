# 案例集：整理规范模板

> **这是一份模板，不是成品。**
> 适用于「把一批散落在资料里的**实例／案例**单独编成一本书」。与《本地资料成书规范》是姊妹关系：
> 那本讲**方法与体系**，这本收**实例与推断过程**。复制到你的项目里改占位符即可。

---

## 一、缘起与定位

把 `<资料目录>` 那批资料里的**实例**单独编成一本书。

- `<主干书>`＝ 体系与方法（讲义、框架、口诀）。
- **本书**＝ 案例集（一批真实实例 + 完整分析过程 + 验证反馈）。

**两个定位先写清楚**，它决定了稿子的写法：主干书写「方法怎么说」，案例集写「方法落在具体实例上是什么样」。

## 二、源材料

源材料通常来自主干书阶段的 OCR 文本（`<项目根>/book8/materials-ocr/`）或课堂记录。

```
| 文件 | 页数 | 说明 |
|---|---|---|
| <文件A> | <页数> | |
| <文件B> | <页数> | 实例最密 |
| … | | |
```

**先切分去重、再精选**，并把数量写下来（如「初筛 699 例 → 去重 299 例 → 精选 129 例」）。

**每个节的素材预先切好**放在 `cases/volN_sM.txt`：每条都是「案例头（出处／要素／年份／重出于／讨论篇幅）+ 完整讨论正文」。**子代理直接读这个文件写稿**，不要去翻几十万字的原始 OCR（除非要核对某处数据）。

## 三、成书结构（三级大纲：卷 → 节 → 例）

```
# <书名>                      ← H1（书名）
## 卷一　<主题>                ← H2（卷）
### 第一节　<节题>             ← H3（节）
（正文中每一例用「例一」「例二」起段，不用标题）
```

- **卷**：按**主题维度**分（不是按资料年份、班次）。分卷维度要「穷尽且互斥」，卷名齐整可对仗。
- **节**：每卷 2~4 节。
- **例**：每例一段（可多段），以「例一」「例二」…开头。

## 四、分卷与节次

```
| 卷 | 节数 | 例数 |
|---|---|---|
| 卷一　<主题一> | | |
| 卷二　<主题二> | | |
| … | | |
| 合计 | | |
```

- 所有卷的例数合计必须等于精选总数（写脚本 assert）。
- 卷内顺序＝**原资料出现顺序**（不要按「由浅入深」重排，会打乱讲授者既有的引用链）。

## 五、写作要求

1. **纯文本，无列表、无加粗、无三级以下标题**。分点用「一、」「（一）」「①」在段首。
2. **每一例必须写全四件事**（这是本书的价值所在，缺一不可）：
   - **要素**：本例的核心数据/条件，写全、写准（格式示例写在第四节里，务必统一）。
   - **演变/背景**：与要素配套的时间线或过程（如有）。
   - **分析过程**：给出推理链条，不是只给结论。
   - **结论与验证**：逐条给出判断，并写明实际结果／反馈（**这是案例集区别于理论书的地方**——断对了什么、当事人实际情况如何）。
3. **保留讲授者的原话判断与口诀**，这是传承所在，不要改写成书面化的同义语。
4. **课堂问答与反馈要转写处理**：源材料里大量的「学员：……」「反馈：……对！」是课堂对话。**对话中的关键信息必须提炼进正文**，但改成陈述句，不要用「学员问」「反馈说」这种对话体，也不要写成报道腔。
5. **删掉课堂寒暄、跑题、重复、口头禅**。篇幅按素材厚薄定：源讨论 3000 字以上的写到 2500~3500 字，1000 字左右的写到 1200~1800 字。**宁可多留推理逻辑，不要压缩成结论清单。**
6. **人名、公司名、地名一律泛化**；但**数据要素、时间、类别、量级一律照实**。
7. 术语规范写死在第四节；**本门特有说法保留，不要"纠正"成通用词**。
8. 引文口诀用中文引号照录，不改字。
9. 不评价、不引申当代政治人物。
10. 每卷末可加一小段「本卷要点」（用「本卷要点」起段，非标题），把该主题的规律串一遍。
11. **全书零品牌名与讲授者姓名**：不得出现特定品牌名、体系名与讲授者姓名，以及任何与之关联的变体表述；指称用中性说法（「本门」「这套体系」＋领域名）与「老师」。
12. 若主干书做过「体系抽离」，本书要同步声明**以什么为主、不用什么作全书框架**（同《本地资料成书规范》第五节第 9 条）。

## 六、案例数据纠错（**最重要，务必逐字核对**）

案例集的核心数据（编号、日期、数值、专有符号）一旦错，整例作废。做法：

1. 建一张「OCR 误识 → 正确」对照表，把**形近字/形近符号**列全。
2. **三重校验法**（每例的核心数据都要过一遍）：
   - **内部一致性**：同一组数据内部必须自洽；组合错了必有一处误识。
   - **合法取值校验**：每个值必须落在本领域的合法集合内（对照标准表、编号表）。
   - **交叉互校**：素材表头里 `重出于` 列出同一案例在其他文件出现的页码；有疑问时去那些地方对照（同一案例在不同场次反复讲过）。
3. 结论：**凡有疑问，一律回 `<项目根>/book8/materials-ocr/` 对应文件对应页核对**，不凭印象改，也不照抄 OCR 错字。

## 七、校验口径

- 每份稿件 `## ` 数量 = 1（节标题），无 `### `、无 `**`、无行首 `- ` 或 `* `。
- 每例都具备「要素 + 演变 + 分析 + 结论验证」四要素，缺一不可。
- 核心数据通过内部一致性与合法取值校验，无 OCR 误字残留在正文里。
- 无报道腔（「他指出」「据了解」「如上所述」「值得注意」）。
- 无对话体残留（「学员问」「反馈说」）。
- 人名地名已泛化；全文无品牌名与讲授者姓名。
