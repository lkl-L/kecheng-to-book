# 《命例集》编纂规范

## 一、缘起与定位

用户的要求：把 `<资料目录>` 那批资料的实战命例单独编成一本书。

《基础教程》（book8，5 编 22 章 31.7 万字）已经交付，讲的是**方法与体系**。本书是它的**姊妹篇**，专门收**实战命例**——历年精修班里老师当场断过的真实八字，一例一断，看的是方法怎么落到具体命上。

姊妹篇定位：
- 《基础教程》＝ 讲义（体系、方法、口诀）
- 本书《命例集》＝ 案例（一批真实八字 + 完整推断过程 + 验证反馈）

## 五、写作要求

1. **纯文本，无列表、无加粗、无三级以下标题**。分点用「一、」「（一）」「①」在段首。
2. **每一例必须写全四件事**（这是本书的价值所在，缺一不可）：
   - 八字四柱：写成「年柱X、月柱X、日柱X、时柱X」或「乾造（坤造）甲子　乙丑　丙寅　丁卯」式的完整四柱，并标明乾造（男）或坤造（女）；
   - 大运排列：起运岁数与各步干支；
   - 命局结构分析：定季节、看配置、分家里家外、寻根基找去处、辨真假虚实、定做功与层次；
   - 推断结论与应期：按专题逐条给出判断，关键流年写出年份干支与应事。
3. **保留老师的原话判断与口诀**（如「有禄无生普通人」「食神制杀」「归禄格」「印禄相随」），这是体系的真传，不要改写成书面化的同义语。
4. **学员问答与反馈要转写处理**：源材料里大量的「学员：……」「反馈：……对！」是课堂对话。**对话中的关键信息（断对了什么、当事人实际情况）必须提炼进正文**，但改写成陈述句，不要再用「学员问」「反馈说」这种对话体，也不要写成报道腔。
5. **删掉课堂寒暄、跑题、重复、口头禅**（「能理解不」「明白了没」「对吧」「这个这个」），一例的篇幅按源材料的厚薄定：源讨论 3000 字以上的写到 2500~3500 字，1000 字左右的写到 1200~1800 字。**宁可多留判断逻辑，不要压缩成结论清单。**
6. **人名、公司名、地名一律泛化**：「某先生」「某女士」「某总」「某学员」「某地」「某公司」「某品牌」。但**干支、大运、流年、年份、职业类别、疾病类别、金额量级一律照实**。
7. 术语规范：十神用规范全称；本门用「穿」不用「害」；「墓库」「燥土」「湿土」写法规范。
8. 引文口诀用中文引号照录，不改字。
9. 当代政治人物不评价、不引申。
10. 每卷末可加一小段「本卷要点」（用「本卷要点」起段，非标题），把该主题的断法串一遍。
11. **全书零品牌名与讲授者姓名**：不得出现特定品牌名、体系名与讲授者姓名，以及任何与之关联的变体表述。需要指称这门学问时，用「本门」「这套体系」「盲派八字」「八字命理」等中性说法；指称讲授者时用「老师」。
12. **不作「道法自然」体系的书**：本书以理法为主，用理法、技法、象法三法断命。正文不出现「道法自然」四字，不引用以它为总纲的论述，也不用「自然法则 / 生存法则」作章节骨架；不单列季节、四时、节气的专章专节（此一层已在姊妹书《基础教程》中抽出，另成独立的一册）。命例推断中必须用到季节寒暖、死活配置时，落在理法与象法的表述上即可，只作具体命例的依据，不作全书框架。

## 六、OCR 干支纠错（**最重要，务必逐字核对**）

OCR 对干支字形误识严重，写稿时必须纠正。下表是实测高频误识：

| OCR 误识 | 正确 | | OCR 误识 | 正确 |
|---|---|---|---|---|
| 葵 | 癸 | | 王 | 壬 |
| 已 | 巳（也可为「己」，看位置） | | 戍 | 戌 |
| 己 / 已 混用 | 己（天干第六）／巳（地支第六） | | 末 | 未 |
| 卵 | 卯 | | 玄 | 亥 |
| 西 | 酉 | | 五 | 丑 |
| 丙 / 內 | 丙 | | 庚 / 康 | 庚 |

**三重校验法**（每例四柱都要过一遍）：
1. **阴阳相配**：同一柱的天干与地支必须同阴阳（阳干配阳支、阴干配阴支）。若 OCR 给出「甲丑」这类组合，必有一字误识。
2. **六十甲子**：每一柱都必须是六十甲子中的一柱（如「戌」只能配甲丙戊庚壬）。
3. **跨文件互校**：素材表头里 `重出于` 列出同一命例在其他文件出现的页码，若本处干支有疑问，去那些地方对照（同一命例在不同班次反复讲）。

结论：**凡有疑问的干支，一律去 `book8/materials-ocr/` 对应文件的对应页核对原文**，不要凭印象改，也不要照抄 OCR 的错字。

## 七、校验口径

- 每份稿件 `## ` 数量 = 1（节标题），无 `### `、无 `**`、无行首 `- ` 或 `* `。
- 每例都具备「四柱 + 大运 + 结构分析 + 结论应期」四要素。
- 四柱干支通过阴阳相配与六十甲子校验，无 OCR 误字残留在正文里。
- 无报道腔（「他指出」「据了解」「如上所述」「值得注意」）。
- 无对话体残留（「学员问」「反馈说」「老师问」）。
- 人名地名已泛化，未出现真实姓名、公司名、地名。
- 全文无特定品牌名与讲授者姓名；无「道法自然」四字。
