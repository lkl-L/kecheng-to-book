# 讲师课程转写稿整理规范

本规范约束所有"整理稿"的写作。整理 = 删废话 + 纠错 + 分段，不是重写。

## 一、文体

- 保留**第一人称讲授口吻**（讲师对学员讲课的实录感），改口语为流畅书面语。
- 用"讲述体"：直接叙述知识点，可用"我们""大家"。
- 删掉的话术一律不留痕迹，删后句间要衔接自然。

## 二、必删的废话

1. 寒暄、开场白、仪式感："今天是天赦日""很高兴跟大家见面""私教课的学员朋友们晚上好"等。
2. 口头禅："是吧""对吧""呢""啊""嘛""这个这个""那个那个"、口吃重复。
3. 授课管理："把麦克风打开""我们休息一下""下节课我们继续"等。
4. 推广营销：广告、招学员、提及价格、联系方式（抖音号、公众号等一律删）。
5. 明显的转写幻觉：乱码、外文字符（如泰文）、无意义音节串。
6. 无信息量的重复：同一句话换个说法反复讲超过 2 遍的，只保留讲得最清楚的一遍。

## 四、格式要求（对照式体例）

每节按以下结构组织：

```
## 节标题

【经文】

（本节对应的经文原文段落，按原文分行，一段一至两句）

【讲解】

（整理后的白话讲授内容……）
```

- 每节一个文件，文件首行：`## 节标题`（从源文件名提取，去掉序号前缀，改通顺）。
- 标题**只能有这一个 `##`**，节内不再用任何 markdown 标题、列表、加粗。
- 【经文】【讲解】两个标记独占一行，是普通文本行，不加粗不加括号以外的符号。
- **无对应经文的节**（如总纲、总结课）：省略【经文】块，标题下直接写【讲解】。
- 经文摘录规则：从 `scripture/sec-XX.txt` 中摘出**本节实际讲到的段落**；一节对应多星/多章时只摘本节讲到的部分；拿不准就少量多摘，但不要把明显无关的星体/章节贴进来。经文按原文分行，保持诗句的行结构（原文一段两句的就两三句一行）。
- 按话题自然分段，每段 150~400 字，段间空一行。讲解部分【讲解】标记之后开始。
- 保留原有内容顺序，不重排、不合并知识点、不自己补充内容。
- 删减后讲解篇幅**参考**为源稿的 55%~75%；源稿重复复述、广告、闲聊极多时可更低（低至 25% 也可以），**判定标准是知识点全覆盖**，不是比例。宁可低于比例，不可漏掉知识点；也不要把重复复述当成"知识点"保留。
- 输出为 UTF-8 纯 markdown，无 YAML，无代码块。

## 五、经文原文对照（重要）

本课程配有经文原文（经专家校注的版本），目录：`<项目根>\book\scripture\sec-XX.txt`（XX 为两位节号，如 09）。

1. 整理第 N 节前，若存在 `scripture/sec-N.txt`，先读它。
2. 转写稿中讲师**念诵/引用的经文句子**，凡与原文可对应的，一律按原文校正字词（转写同音错字很多，如"汉龙"→"撼龙"、"陆存"→"禄存"）。
3. 讲解中引用经文时保留引号并保持原文用词；讲师对经文的白话解释照转写稿整理，不改写成原文。
4. 经文片段只是校正参照，**不要**把整段原文粘贴进整理稿——书中出现经文只限于讲稿里自然引用的部分。

《雪心赋》课程（11 课）的经文对照文件是单文件：`<项目根>\book\scripture\xuexinfu.txt`（全书约 6500 字，分六章：山川理气 / 地理要略 / 论山水本源 / 论水法 / 论龙脉与穴法 / 论阳宅与结语）。整理时通读该文件，按本节讲到的内容摘取对应赋文段落做【经文】块，其余规则同上。

《地理千金赋》课程（02 课，9 节）的经文对照目录：`<项目根>\book\scripture\diqianjin\`。底本是【品牌名】说讲师 2020 年 3 月校对本（用户提供 PDF，已转简体，共 49 句）：全文见 `diqianjin.txt`，逐节片段见 `sec-01.txt ~ sec-09.txt`。每节【经文】块直接使用对应 sec 文件里的赋文句子（切分参考值已在文件内注明，若源稿实际内容与片段范围有出入，以源稿为准微调，但全书合计必须覆盖全部 49 句且不重复）。其余规则同上。

注意：千金赋课程为逐句讲解课，与撼龙经课不同——【经文】块是本书体例的正式组成部分（不是只做校正参照），每节开头必须贴出本节讲到的赋文原句。

《某日课课程》课程（30 课，源目录 `某日课课程（音频 30 集）/择日音频30集`）的特殊说明：

本课**没有经典经文**，但配有作者整理的**讲义 PDF**（每课一份，已提取为纯文本：`<项目根>\book\materials\rike\讲义NN.txt`，NN 为课号 01-30）。讲义与音频是同一讲的两个版本：讲义文字干净、结构清晰（带"一、例子 二、原理"式小节），但部分课比音频简略；音频内容常更全，但同音错字多。

整理规则：
1. 每课一节的【经文】块**省略**（无经文），标题下直接写【讲解】。
2. 以**讲义的结构顺序为骨架**（保留其小节划分与先后），把音频转写稿中更详细的展开、案例细节、白话解释融合进来，形成一篇连贯的讲授文字。讲义有而音频没有的知识点（口诀、干支表、原则条目）必须保留；音频有而讲义没有的内容也保留（第 5、9 课等音频明显更全）。
3. 讲义中的**干支四柱**是竖排两行（天干一行、地支一行），整理时还原为一行四柱：如"壬寅年 壬寅月 戊子日 壬戌时"，或按讲义通书格式写"壬 壬 戊 壬／寅 寅 子 戌"。**干支字必须逐字照讲义核对**，音频转写的干支几乎全错（如"物子日"应为"戊子日"）。人名、卦名、神煞名同样以讲义为准。
4. 讲义中的图片占位说明（如"（2021-2022 年三煞通书图片）""（下图）"）一律删除；若音频对图中内容有讲解则融入正文。
5. 讲义开头的课程介绍页（"主讲人""讲课期间请勿发语音""课后讨论请移步…"）与音频开头的寒暄，均按第二节必删废话处理。
6. 部分课的主讲人是另一位讲授者（另一位讲师），书中同样用第一人称，不点名。
7. 第 11、22 课原音频转写稿被"栏目"水印刷屏污染（有效内容不足三成），已从原始 mp3 补转，补转稿在 `transcribe\out\某日课课程（音频 30 集）\择日音频30集\` 下；若整理时该目录存在对应文件，以补转稿为音频依据。

《卫星地图阴阳宅综合运用》课程（05 课，十节）的特殊说明：

本课是**纯实战课，没有经典经文，也没有讲义文档**——全程对着卫星地图讲城市与龙穴的优劣判别，转写稿就是唯一素材。【经文】块一律省略，标题下直接写【讲解】。

整理规则：
1. **图中内容必须转成文字**。这是本课最大的特点：讲师在卫星图上画线、圈点、标方位，讲稿里充满"我现在把这个点标一下""大家看这条水从这里绕过来"这类指向性的话。短视频（用户已确认本书不配图）——凡是他用图讲的知识点，必须**用文字把地形关系讲清楚**：来龙从哪个方位入首、水从哪边来、哪边去、砂在哪一侧、明堂如何、穴（或小区/楼盘）处在什么位置。指向性的空话（"大家看这个位置"）删掉，但**指向的对象与其地形关系不能删**。
2. 案例地名的处理：**公开的名山大川、城市、名人故居/陵墓（如故宫、明十三陵、孙中山故居、李嘉诚祖坟、沈万三故居、乐山、韩江等）保留原名**——这些是本课的骨架素材；普通客户的私人宅第、楼盘、村庄，按内容安全规则泛化为"某地""某小区""某先生的宅子"。陌生人名一律泛化。
3. 卫星图课程涉及**现代城市、当代人物**，涉及国家领导人、政治人物的祖坟/故居案例（如毛主席祖母墓等），按前面各书口径照实整理，只讲风水地形，不涉政治评价。

【体例】
1. **经典导读类 15 节用对照式**【经文】+【讲解】（14、15、16、17、21、22、23、24、30、31、32、33、35、36、38）：【经文】块贴出本节讲义中**成段引用的经典原文**（按讲义原样、保持分行，凡讲义中"某某书曰/原文/经文"下的整段引文都归入），【讲解】块写整理后的讲授。其余 31 节**只有【讲解】**（标题下直接写【讲解】）。拿不准某节是否有成段引文时，以讲义实际内容为准；若讲义通篇无成段引文，就只写【讲解】。
2. **掌诀内容并入所属主节**：10 份掌诀短稿的内容并入其编号对应的主节（(11)→第 11 节、(12)→第 12 节、(26)→第 26 节、(34)→第 34 节、(37)→第 37 节），作为该节末尾的一两段"掌诀演示"内容融入讲解，不单独成节、不单独编号。
3. **第 25 节（会员试题、答案和讲解）**是试卷讲评：原试题的问题保留（可转述），答案与讲解整理成连贯文字，仍用【讲解】（或按题号分段的讲述体），合为一节。
4. 讲义中反复出现的版头广告（`【真风水，【品牌名】说】`、`【公众号：【品牌名】说】内部资料，版权所有，盗版必究`、`加入会员，联系客服：【手机号】…`、`（讲师推介、扫码加入微课堂等）`、`（会员招生与付费教材的推广文案）`）**全部删除**。音频里的口播（"真风水【品牌名】说，我是【品牌名】的讲授者""益友们晚上好"）、招生推广、寒暄、休息闲聊同样删除。
5. 讲义中"图片里面显示的就是……""这幅图是……""（如上图）"这类**图片指代**：本书不配图，图片指代删掉，但图上讲的内容（人物、事件、数据、地形关系）必须用文字保留。
6. 讲义中出现 `【编者按】` 标记的是编者补注，内容照留、标记去掉。讲义里的口语化板书（"我们看一下原文"）可精简。
7. 内容安全：公开历史人物、公开典籍、公开事件（如慕尼黑惨案、北京奥运、阿里巴巴上市）保留；普通客户、学员姓名与私人宅第一律泛化（"某先生""某位学员"）。涉及当代政治人物的内容不评价、不引申，只按风水知识照实整理。
8. **标点统一用中文全角**：引号一律用 `“”`（内层用 `‘’`），**不得用半角 `"`**；顿号、逗号、句号、问号、书名号全部全角。子代理各写各的会半角中文混杂，合书前由主控跑一次统一脚本兜底。
9. **节标题只写讲题**：首行 `## 讲题`（不带"第N讲"、不带书名），讲次编号由合并脚本在分卷时统一加上（`### 第N讲　讲题`）。

## 六、流程要求

1. 先读本规范，再读源稿。
2. 源稿**必须读到最后一行**；读不完用 offset/limit 续读，不许只读开头就动笔。
3. 写完自检：无报道腔（"他说/他指出"）、无列表加粗、`##` 数量为 1、通篇无未校正的"汉龙/仪龙"。
4. 回报：文件绝对路径 + 整理后字数 + 本节主要话题（两三个词），不要复述正文。
