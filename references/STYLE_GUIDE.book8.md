## 三、成书结构（三级大纲：编 → 章 → 节）

```
# 《基础教程》精讲实录          ← H1
## 第一编　八字的原理与基础          ← H2（编）
### 第一章　什么是八字               ← H3（章）
（章内用自然段分节，节标题用【】或直接以"一、二、"起段）
```

- **编**：5 编，各带一句编前说明（排在同一张扉页下半部）。
- **章**：每章独立成稿，文件名 `sec-md/bz-NNN.md`，首行 `## 第N章　章名`（节标题只用 `二、` 等正文内小标）。
- 每章目标 8000~20000 字，全书目标 20~25 万字。

## 五、写作要求

1. **纯文本、无列表、无加粗**；正文用自然段。章内小节如需分点，用「一、」「二、」「（一）」「①」等中文序号起段。
2. 每章末可附「本章小结」一段（不加标题以外的修饰）。
3. 术语规范：干支一律用"甲、乙、丙、丁…""子、丑、寅、卯…"；五行用"金木水火土"；十神用规范全称（正印、偏印、比肩、劫财、食神、伤官、正财、偏财、正官、七杀）。
4. 错字与口语渣：源资料是课堂记录，有大量口语、重复、断句混乱、同音错字。整理时**删口语、并重复、补断句**，保留全部知识点与命理判断逻辑。
5. 命例中的**真实人名、公司名、地名一律泛化**（"某总""某学员""某地"），八字干支、大运流年、判断结论照实保留。
6. 涉及疾病、灾祸的具体描述保留（这是知识点），但避免渲染细节。
7. 引文与口诀（如"金多火熄""独阴不生孤阳不长"）用引号照录，不改字。
8. 当代政治人物不评价、不引申。

## 六、校验口径

- 每章 `## ` 数量 = 1（章标题），无 `### `、无 `**`、无行首 `- ` 或 `* `。
- 术语错字零残留（下表）。
- 无报道腔（"他指出""据了解""如上所述"）。
- 命例干支与大运流年数字核对无误（来源照抄，不自行推算）。
