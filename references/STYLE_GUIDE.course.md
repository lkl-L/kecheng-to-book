# 课程音视频成书：整理规范模板

> **这是一份模板，不是成品。**
> 开工前把它复制到你的项目里（如 `<项目根>/book/STYLE_GUIDE.md`），把尖括号与方括号占位符换成你自己的内容；
> 之后**每加一门课，就在第三节追加一节「本课专用说明 + 错字对照表」**。
> 派给子代理的每一份 prompt 都要求它**完整读这份文件**——它是整理质量的总闸门，写得越具体，子代理跑偏越少。

本规范约束所有「整理稿」的写作。整理 = **删废话 + 纠错 + 分段**，不是重写。

---

## 一、文体

- 保留**第一人称讲授口吻**（讲授者对听众讲课的实录感），把口语改成流畅的书面语。
- 用「讲述体」：直接叙述知识点，可以用「我们」「大家」。
- 删掉的话术一律**不留痕迹**（不要写「（此处省略）」「（笑声）」之类），删后句间要衔接自然。

## 二、必删的废话

1. 寒暄、开场白、仪式感：「大家好」「很高兴见到各位」「今天是个好日子」等。
2. 口头禅：「是吧」「对吧」「呢」「啊」「嘛」「这个这个」「那个那个」，以及口吃重复。
3. 授课管理：「把麦克风打开」「我们休息一下」「下节课继续」等。
4. 推广营销：广告、招生、提及价格、联系方式（账号、公众号、二维码一律删）。
5. 明显的转写幻觉：乱码、外文字符、无意义音节串。
6. 无信息量的重复：同一句话换说法反复讲超过两遍的，只留讲得最清楚的一遍。

## 三、错字对照表（**每门课各自追加一节**）

转写稿的错字有两类：**通用错别字**（各课都有）和**课程专有名词的同音误写**（每门课不同，且是最大问题源）。

**维护方法**：

1. 第四节写明每门课的**源目录、讲义/参考文本路径、输出前缀**，以及该课的特殊体例与注意事项。
2. 第五节给该课一份**错字对照表**，用下面这个格式；表要**边整理边补**——子代理报回来的新错字立刻追加。
3. 表里凡是**品牌名、机构名、讲授者姓名**，一律写成占位符（`【品牌名】`／`【机构名】`／`【讲授者】`），正文里用中性说法，不做品牌关联（见第十节）。
4. **拿不准的术语不要硬改**：先看参考文本，再按本领域常识判断，宁保守勿造词。

```
| 转写错字 | 正确 | 说明 |
|---|---|---|
| 通用错别字示例：己经 | 已经 | 各课都出现 |
| 专有名词示例：专有术语A 的同音误写 | 专有术语A | 以参考文本为准逐字核对 |
| 人名同音误写 | 【人物名】 | 公开历史人物照原名，私人一律泛化 |
| 数字/单位误识 | 正确写法 | 以讲义或参考文本为准 |
```

> 示例：某门课的整理稿里「己经／因该／以经」是通用错别字；某专有名词被误写成两三种同音形式，必须按参考文本统一。

## 四、格式要求（对照式体例）

每节按下面结构组织：

```
## 节标题

【原文】

（本节对应的权威文本段落，按原文分行）

【讲解】

（整理后的讲授内容……）
```

- 每节一个文件，文件首行 `## 节标题`（从源文件名提取，去掉序号前缀，改通顺）。
- 标题**只能有这一个 `##`**；节内不再用任何 markdown 标题、列表、加粗。
- `【原文】`／`【讲解】` 两个标记**独占一行**，是普通文本行，不加粗、不加多余符号。
- **无对应原文的节**（总纲、总结、答疑课）：省略 `【原文】` 块，标题下直接写 `【讲解】`。
- **原文摘录规则**：从参考文本目录（见下节）中摘出**本节实际讲到的那几段**；一节对应多处时只摘本节讲到的部分；拿不准就少摘，不要把明显无关的段落贴进来。原文按原式分行。
- 按话题自然分段，每段 150~400 字，段间空一行。
- **保留原有内容顺序**，不重排、不合并知识点、不自行补充内容。
- 删减后的讲解篇幅**参考**为源稿的 55%~75%；源稿重复、闲聊极多时可更低（低到 25% 也可以）。**判定标准是知识点全覆盖**，不是比例——宁可低于比例，不可漏掉知识点；也不要把重复复述当「知识点」保留。
- 输出为 UTF-8 纯 markdown，无 YAML、无代码块。

## 五、参考文本对照（有则必用，质量杠杆最大）

若课程配套了**权威文本**（教材、原典、行业标准、讲授者本人校订的讲义），**先建好这个目录**再开工：

```
<项目根>/book/scripture/<课程>/        # 原文、标准文本、校订本
<项目根>/book/materials/<课程>/        # 讲义 PDF/docx 提取出的纯文本
```

1. 整理第 N 节前，若存在对应参考文本，**先读它**。
2. 转写稿里讲授者**念诵／引用的原文句子**，凡能与参考文本对应的，一律按参考文本校正字词（转写同音错字极多）。
3. 讲解中引用原文时保留引号并保持原文用词；讲授者的白话解释照转写稿整理，不改写成原文。
4. 原文片段只是校正参照，**不要把整段粘贴进整理稿**——书中出现原文只限于讲稿里自然引用的部分。
   （例外：若某门课是**逐句讲解课**，`【原文】` 块就是体例的正式组成部分，每节开头必须贴出本节讲到的原句，此时按第六节的切分清单核对"全覆盖且不重复"。）

## 六、逐句讲解课的分节切分（如适用）

- 按节把原文切成 `sec-NN.txt`（两位节号），另写一份 `split_map.md` 记录每节覆盖范围。
- 全书合计必须**覆盖全部句子且不重复**；整理完跑一次"原文覆盖核对"（用句首 10 字去标点后匹配）。
- 相邻节容易重复/遗漏，合并前必查。

## 七、流程要求

1. 先读本规范，再读源稿。
2. 源稿**必须读到最后一行**；读不完用 offset/limit 续读，不许只读开头就动笔。
3. 写完自检：无报道腔（「他说」「他指出」「据了解」）、无列表无加粗、`##` 数量为 1、错字表零残留。
4. 回报：文件绝对路径 + 整理后字数 + 本节主要话题（两三个词），不要复述正文。

## 八、内容安全与去关联（所有书通用）

- 普通客户、听众、学员的姓名与私人信息一律泛化（「某先生」「某位学员」「某地」「某公司」）。
- 公开的典籍、历史人物、公共事件照实保留。
- 不评价、不引申当代政治人物。
- 不出现任何品牌名、机构名、讲授者姓名及其变体表述；指称讲授者用「老师」，指称这门学问用中性说法（「本门」「这套体系」＋领域名，如「这套方法」「这套理论」）。
- 涉及具体人名/地名的案例，先判断是「公开素材」还是「私人信息」——前者保留，后者泛化。
